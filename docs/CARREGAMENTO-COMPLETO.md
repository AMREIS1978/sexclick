# SEXCLICK 1.2 — pacote completo para um WordPress NOVO

Este é o pacote para a opção de carregamento de ficheiros de um site PHP/WordPress. Contém index.php diretamente na raiz, WordPress e WooCommerce oficiais, tema SEXCLICK e assistente inicial. Não contém uma pasta exterior nem ZIP dentro de ZIP.

1. Para uma instalação NOVA, carregar SEXCLICK-SITE-COMPLETO-HOSTINGER-1.2.zip. Se usar o Gestor de Ficheiros, extrair o conteúdo na pasta atribuída ao novo site: index.php, wp-admin, wp-includes e wp-content ficam diretamente nessa pasta.
2. Concluir a configuração normal do WordPress: ligação à base de dados e criação da conta de administrador. O instalador do alojamento pode realizar parte destes passos. Se WordPress solicitar dados MySQL, utilizar os dados da base de dados própria desta instalação. As credenciais não são fornecidas neste pacote. Não enviar palavras-passe no chat.
3. Entrar no painel WordPress e clicar no aviso «Preparar a minha loja SEXCLICK». O botão ativa os ficheiros locais do WooCommerce/SEXCLICK, prepara páginas e menu e usa EUR/PT. Não descarrega plugins durante essa ação. Só se destina a uma loja nova, sem produtos nem encomendas.
4. Abrir WooCommerce > SEXCLICK · Dreamlove e rever as dependências. Carregar a fotografia principal em Aparência > Personalizar > SEXCLICK — Imagem principal.
5. Configurar os dados reais do vendedor, pagamentos, envios, faturação e conector Dreamlove. As vendas continuam bloqueadas até concluir os testes e ativar a loja. Não existem produtos ou pagamentos de demonstração.

Não sobrepor este arquivo a uma instalação existente: contém ficheiros de WordPress e WooCommerce. Preservar o site atual e usar uma instalação separada em /loja, ou uma pasta atribuída a um site novo. Para atualizar um WordPress existente, usar os ZIP separados de tema e plugin.

Este pacote não é uma exportação com base de dados SQL de uma loja em funcionamento. Se o fluxo de migração exigir expressamente uma base de dados/backup instalado, utilizar a instalação nova de WordPress em vez de apresentar este arquivo como esse backup. Não está garantida a classificação automática do arquivo pela Hostinger.

HTTPS depende de DNS e de certificado válido emitido pelo alojamento. O pacote não pode emitir ou reparar SSL. As imagens originais não foram recuperadas e a integração Dreamlove ainda não está ativa.
